RelicOS updates
===============

Copy a RelicOS update file here -- relicos-r36s-<version>.raucb -- from
any PC, put the card back, turn the console on, and in the menu choose
UPDATES > START UPDATE. The console checks the file (it must be signed
by RelicOS and built for this device), writes the new system into the
copy of the system that is not in use (about a minute), and asks you to
reboot. APPLY UPDATE reboots into the new version; if the new version
fails to start three times, the console goes back to the previous one
by itself. Your games, saves and settings are not touched by an update.

After a successful update the file is renamed *.installed; you can
delete it. Only the newest .raucb here is offered. If the menu says
there is no update file, check the name ends in .raucb and that it is
in this folder, not a subfolder.
